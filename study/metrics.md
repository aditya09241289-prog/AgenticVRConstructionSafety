# Metrics captured by the prototype

Each JSONL session log can capture:

- participant_id (use pseudonymous IDs)
- condition (adaptive/fixed)
- hazard_type
- success/failure
- response_time_ms
- severity
- current difficulty
- generated instructional cue
- agent reason
- learner skill score

For a real pilot, avoid storing names in the telemetry logs. Keep consent/contact information separate from study identifiers.
