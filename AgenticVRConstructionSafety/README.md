# Agentic AI for VR Construction Safety

## Overview

This project presents a laptop-based virtual construction safety training
environment combined with an adaptive AI training agent.

The system simulates construction-site hazards and observes learner
responses. A Python backend maintains a learner model and applies a
pedagogical decision policy to adapt subsequent training scenarios.

## Main Hazards

- Fall hazards
- Struck-by hazards
- Electrical hazards

## System Architecture

Unity Construction Safety Simulation
        |
        | Learner responses
        v
Python FastAPI Backend
        |
        v
Learner Model
        |
        v
Pedagogical Agent
        |
        v
Adaptive Training Decision
        |
        +--> Next hazard
        +--> Difficulty adjustment
        +--> Remediation instruction
        +--> Scenario repetition

## Adaptive Behaviour

The adaptive condition uses learner performance to determine subsequent
training actions.

Successful responses can result in:

- Scenario advancement
- Difficulty increases after sustained successful performance

Incorrect responses can result in:

- Corrective safety instructions
- Scenario repetition
- Difficulty reduction

The system also includes a fixed-condition pathway using a predefined
scenario sequence for future comparison experiments.

## Learner Telemetry

The system records:

- Hazard type
- Success or failure
- Response time
- Hazard severity
- Training session ID
- Agent decision
- Scenario difficulty

## Metrics

The backend calculates:

- Overall success rate
- Average response time
- Hazard-specific accuracy
- Initial difficulty
- Average difficulty
- Maximum difficulty
- Number of adaptive decisions
- Remediation instructions
- Difficulty increases
- Scenario advances
- Agent action distribution
- Difficulty progression
